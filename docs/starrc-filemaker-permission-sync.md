# StarRC × FileMaker 账号权限对应

## 当前基线

2026-07-24 已在 FileMaker Pro 的“文件 → 管理 → 安全性”中完成只读盘点：

- 97 个账号
- 91 个启用账号、6 个停用账号
- 39 个权限集
- 38 个权限集正在被账号使用
- 15 个扩展权限
- 1 个当前界面可见的文件访问授权（`DMS`）

StarRC 后台已经同步 97 个账号映射和 39 个权限集策略。账号密码仍只保存在 FileMaker，
同步过程没有读取或保存密码。

## FileMaker 实际权限发现

- `[完全访问权限]` 和 `Master` 可以管理账号并访问全部业务数据，映射为 StarRC 管理员。
- `業務部`、`業務經理`、`特別助理`、`貿易產品入資料`、`貿易經理`、
  `TW財務總監 访问权限` 明确拥有价格表或贸易价格表访问。
- `貨款對帳` 需要订单金额用于财务对账，StarRC 允许查看价格与金额，但不开放库存、BOM
  或系统管理。
- `設計部`、采购、仓库等权限集不能访问专门的客户价格和贸易价格表，因此 StarRC 默认
  不开放价格。
- 多个不应看价格的权限集仍对 `INDEX` 表拥有全部字段访问。`INDEX` 包含批次价格、货值
  等可能的财务字段，因此 FileMaker 原生界面仍有间接暴露风险；StarRC 会在响应层再次
  删除这些字段。
- 抽查的业务权限集对 `ProductPrice::price` 具有可修改权限。FileMaker 侧后续应区分
  “可查看价格”和“可维护价格”，避免销售账号普遍拥有价格写权限。
- 多数自定义权限集允许执行全部脚本；部分角色还允许打印或导出。后续应继续核对价格打印、
  报价、导出和批量价格脚本。
- `fmrest` 和 `fmodata` 目前只授予 `[完全访问权限]`；普通员工权限集没有 Data API 或
  OData 访问，这是合理的服务边界。
- `fmapp` 与 `fmwebdirect` 几乎授予所有在用权限集；不需要 WebDirect 的生产、仓库、
  包装等角色可以进一步收紧。

当前 StarRC 映射结果：

- 97 个账号已进入后台账号管理。
- 6 个 FileMaker 停用账号在 StarRC 同样停用。
- 20 个账号允许查看价格，77 个账号隐藏价格。
- 39 个实际 FileMaker 权限集全部写入后台策略。

## 已实现的对应方式

FileMaker 继续负责账号认证、密码和数据库原生权限。统一 WebViewer 签名载荷必须包含：

```filemaker
[ "operator.account" ; Get ( AccountName ) ; JSONString ] ;
[ "operator.name" ; Get ( UserName ) ; JSONString ] ;
[ "operator.privilege" ; Get ( AccountPrivilegeSetName ) ; JSONString ] ;
[ "operator.persistentId" ; Get ( PersistentID ) ; JSONString ]
```

StarRC 后台收到有效签名后，把账号与实际权限集写入：

- `webviewer_account_control`
- `webviewer_privilege_set_control`

账号改用其他 FileMaker 权限集后，下一次请求会自动同步实际权限集。StarRC 管理员可以按
权限集设置默认权限，也可以为单个账号覆盖。停用或修改权限后，旧会话下一次请求立即按新
设定校验。

账号级设置只保存与权限集不同的项目。例如只打开某个销售账号的“查看价格”，该账号的
产品、订单、库存等权限仍继续继承销售权限集，之后修改权限集时不会被旧值冻结。

后台不创建 FileMaker 账号，也不保存 FileMaker 密码。管理员页面里的“绑定账号”只创建
StarRC 权限映射；账号和密码仍必须在 FileMaker“安全性”中维护。

StarRC 管理页参考 MayakoFM 的账号管理方式，提供账号概览、状态和价格快捷开关、账号
搜索/筛选、详细权限编辑，以及按 FileMaker 权限集批量设置默认权限。

## StarRC 可控制范围

| StarRC 权限 | 后台控制 | 前端控制 | FileMaker 建议对应 |
|---|---:|---:|---|
| 查看价格 | 询价 403；响应剔除售价、金额、批次价格、成本、报价 | 隐藏价格入口与金额显示 | 限制价格表/字段与价格布局 |
| 账号管理 | 管理接口 403 | 隐藏系统管理入口 | 仅管理权限集使用 |
| 产品资料 | 产品 API 403 | 产品导航禁用 | 对应产品布局/表记录权限 |
| 订单资料 | 订单 API 403 | 订单导航禁用 | 对应订单布局/表记录权限 |
| 库存流水 | 库存 API 403 | 库存入口禁用 | 对应库存布局/表记录权限 |
| BOM / 发料 | BOM、零件、物料编码 API 403 | BOM 与发料入口禁用 | 对应 BOM/零件布局与脚本 |
| 智能问答 | 查询 API 403 | 输入框与预设问题禁用 | 允许读取其业务范围内的数据 |
| RAG 控制 | 索引、OData、分析接口 403 | RAG 入口禁用 | 仅技术管理权限集使用 |
| 合并订单 | 预览和写入接口 403 | 合并按钮禁用 | 允许专用布局与合并操作 |

## 价格保护边界

没有 `canViewPrice` 时，后台会删除名称包含下列语义的字段，而不是只在页面上隐藏：

- `Price`、`unitPrice`、`Retail_Price_USD`
- `產品售價::Price`
- `INDEX::BATCHPRICE`
- 价格、单价、售价、成本、报价、利润、货值
- 订单金额、总金额及 USD 金额字段

自然语言查询中明确询问价格或成本时直接返回 HTTP 403。普通查询即使 FileMaker 服务账号
读到了价格，返回浏览器前也会再次清除相关字段。

原始 `/api/filemaker/*` 接口不属于普通业务查询入口：读取必须具备 `canManageRag`；创建、
修改、删除和执行脚本还必须同时具备 `canManageAccounts`。因此没有价格权限的普通账号不能
通过原始布局、记录或 metadata 接口绕过响应脱敏。

### 财务字段规范名

FileMaker 原字段保持不变，避免影响布局、脚本、计算字段和既有接口。StarRC 在
`backend/config/semantic_mapping.json` 的 `fieldSemantics` 中为财务字段登记规范名：

- `price_`：售价、零售价、客户价、询价价格。
- `cost_`：单位成本、实际成本、内部估价、模具和组装成本。
- `amount_`：订单金额、出库总金额和总价。
- `fee_`：运费及其他费用。
- `value_`：库存货值、预付库存货值。
- `rate_`：汇率、成本加成率、报价系数。

每条映射同时保存 FileMaker 布局、原字段名、业务概念、币种、敏感类型和
`permission: canViewPrice`。响应脱敏优先使用显式映射，未登记的旧字段继续使用保守的
价格关键字兜底。包含 `Price` 但实际是编号的字段必须显式登记为
`sensitivity: identifier`，例如 `ProductPriceID → id_product_price`，避免误判。

FileMaker 侧仍建议建立第二道保护：

1. 普通用户权限集不授予价格表和价格字段的查看权限。
2. 只把 `fmrest` 授予独立 Data API 服务账号，不授予普通员工账号。
3. 普通员工通过 `fmapp` 登录；不需要 WebDirect 的账号不启用 `fmwebdirect`。
4. 价格布局、打印脚本、导出脚本和原始字段查看布局仅向价格权限集开放。
5. 检查 `@products`、订单、BOM、发料布局是否通过相关字段或 portal 间接暴露价格。

## 建议权限集模板

实际 39 个权限集已经按以下控制级别归并，配置保存在
`backend/config/webviewer_privilege_sets.json`：

| 建议级别 | 价格 | 账号管理 | 产品/订单 | 库存/BOM | RAG | 合并订单 |
|---|---:|---:|---:|---:|---:|---:|
| `[Full Access]` / 系统管理员 | 是 | 是 | 是 | 是 | 是 | 是 |
| StarRC 管理员 | 按需 | 是 | 是 | 是 | 是 | 按需 |
| 业务 / 销售 | 按需 | 否 | 是 | 只读 | 否 | 按需 |
| 生产 / 仓库 | 否 | 否 | 订单只读 | 是 | 否 | 否 |
| 普通只读 | 否 | 否 | 只读 | 只读 | 否 | 否 |
| Data API 服务账号 | 仅后端需要 | 否 | 专用布局 | 专用布局 | 后台任务 | 专用写入 |

## FileMaker 安全性核对表

对每个现有权限集记录以下项目，再录入 StarRC 管理页：

1. 权限集准确名称与用途。
2. 使用该权限集的账号数量、启用状态和账号类型。
3. 记录权限：产品、价格、订单、库存、BOM、零件、客户。
4. 布局权限：业务布局、原始数据布局、价格布局、管理布局。
5. 脚本权限：读取、导出、打印、合并、管理员脚本。
6. 值列表权限和自定义菜单。
7. 扩展权限：`fmapp`、`fmrest`、`fmwebdirect` 及其他自定义扩展权限。
8. 是否允许导出、打印、复制、插件和绕过数据输入警告。
9. StarRC 九项权限的对应值，尤其是 `canViewPrice`。

修改 FileMaker 权限集前应先导出/截图现有设定，并使用一个无价格权限测试账号同时验证：

- FileMaker 原生布局看不到价格。
- StarRC 询价返回 403。
- 产品、订单、BOM、RAG 原始响应不包含价格字段。
- 浏览器直接输入受限 API 地址仍然被后台拒绝。
