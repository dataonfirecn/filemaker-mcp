# 管理员客户查看页

入口：系统管理 → 客户资料，或 `/?page=customerDirectory`。

页面只读，展示已同步到 Web 的客户主档，不请求 FileMaker、不修改资料、不启动同步任务。

## 功能

- 每页 50 条，按客户代码及原生 ID 稳定排序。
- 搜索代码、客户 ID、简称、公司、国家/地区或主要业务负责人；搜索文本作为字面量处理。
- 按全部、标识完整、待完善、来源缺失筛选。标识完整只表示代码/简称齐全且代码不重复，不表示所有联系方式已填写或报价已经审核。
- 列表展示代码、名称/公司、国家/地区、主要业务负责人、异常及最后同步时间。
- 详情按基本资料、联系人与地址、业务与备注分组，展示已同步的 19 项字段及来源 ID、版本、资料更新时间、最后同步时间。
- 简称为空时列表可用公司/代码显示，详情保留原始空值并显示“未填写”。异常记录保持可查看，不因此允许新增报价关联。
- 提供加载、空结果、失败重试与权限不足状态；返回列表保留本次搜索和分页条件。

## 权限与接口

系统沿用 `canManageAccounts` 作为管理员边界，与现有“账号与权限”一致，不依赖账号是否字面叫 admin。

- 菜单只向管理员展示；非管理员直接打开页面链接会返回首页，客户组件不挂载。
- `GET /api/admin/customers?q=&status=all&page=1`
- `GET /api/admin/customers/{原生客户ID}`
- 两个接口都先校验管理员权限，再访问当前来源的数据库；未登录 401，非管理员 403，不存在或不属于当前来源的 ID 返回 404。
- 列表不返回联系方式；详情字段以已核实的 19 项白名单过滤，未来存储增加字段不会自动泄漏到接口。
- 成功响应使用 `Cache-Control: no-store`。页面没有编辑、导出或同步操作。
