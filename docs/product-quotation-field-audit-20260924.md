# 产品报价：字段类型、计算逻辑与网页编辑清单

核对日期：2026-09-24。来源：实际「产品报价」布局（ID 237，基于產品）、FileMaker 管理数据库字段定义及自动输入公式、当天 Data API 布局元数据。仅只读查看；字段/公式对话框均取消退出，未修改产品记录、数据库定义或网页代码。

## 范围与结论

主清单覆盖选项卡控件外的 **36 个唯一字段**；EX-Price 与另一 Price 框重复绑定，合并一行。按实际绑定识别，不按页面标签猜测。选项卡/入口内的字段不混入主清单，另补充与主字段计算或报价维护直接相关的来源。

**网页编辑页可以隐藏计算与汇总字段；但 autoEnter（自动输入）不等于 calculation（计算字段）。** 普通字段中的去格式公式仍需要人工输入。系统编号、建档人、BOM 创建日期、PrePaid 虽为普通字段，也不应作为一般产品输入框。

## 2. 主页面全部计算字段：原公式

以下 13 项均在原生字段定义中确认是**未存储计算**，结果随依赖与关联上下文计算，不应作为可提交的编辑值。

### F01 `產品 BOM::產品成本`

```filemaker
(產品成本計算*(1+(產品::成本加成/100)))+產品::組裝成本+產品::其他成本估價
```

BOM 材料合计 × (1+成本加成/100) + 组装成本 + 其他成本；不含包装总工钱。

### F02 `產品 BOM::計算美金`

```filemaker
((產品成本+產品::包裝總工錢) / 產品::匯率 )+產品::提成+產品::提成B
```

加包装工钱后换汇，再加 A/B 积分。

### F03 `產品::建議報價`

```filemaker
產品 BOM::計算美金/((100-報價積數)/100)
```

除以剩余比例，不能实现成美金成本 × (1+报价积数/100)。

### F04 `產品::包裝總工錢`

```filemaker
包裝工錢 + 準備包裝工錢
```

每包包装工钱与准备工钱相加。

### F05 `產品::總人工成本`

```filemaker
組裝成本+包裝總工錢
```

组装成本加包装总工钱。

### F06 `產品::準備包裝工錢`

```filemaker
(時薪 / 60/60) * 準備工時單包
```

时薪换算到每秒，再乘每包准备秒数。

### F07 `產品::包裝工錢`

```filemaker
(時薪 / 60/60) * 包裝工時單包
```

时薪换算到每秒，再乘每包包装秒数。

### F08 `產品::準備工時單包`

```filemaker
((準備工時分*60)+準備工時秒) / 準備工時數量
```

准备总秒数 ÷ 计时数量。

### F09 `產品::包裝工時單包`

```filemaker
((包裝工時分*60)+包裝工時秒) / 準備工時數量
```

包装总秒数也除以「準備工時數量」；原公式就是这个字段，不能擅改成另一数量。

### F10 `產品::stock`

```filemaker
Sum ( 產品庫存::入庫數量 )-Sum(產品庫存::出庫數量)
```

关联产品库存的入库合计减出库合计。

### F11 `產品::有現貨`

```filemaker
If ( stock > 追加訂購的等級 ; "有現貨" ; "追加訂購" )
```

严格大于最低库存才有现货；等于阈值时也显示追加订购。

### F12 `產品::Stock_USD`

```filemaker
stock*產品售價::Price
```

当前库存 × 关联 EX-Price；不是库存 × RMB 成本。

### F13 `產品::BOM計數`

```filemaker
Count ( 產品 BOM::零件編號 )
```

统计关联 BOM 中零件编号非空的项数。

### BOM 成本的上游依赖

```filemaker
產品 BOM::成本x需求數量 = 產品BOM_成本::單位成本 * 需求成本計算數量
產品 BOM::產品成本計算 = 总计 成本x需求數量  // 原生类型：合计（summary）
產品 BOM::產品成本合計 = 產品成本 + 產品::包裝總工錢
```

`產品BOM_成本::單位成本` 是关联的普通数字；`需求成本計算數量` 是 BOM 行中的普通数字，不能用 `需求數量` 或主表 `MOQ` 代替。合计具有 FileMaker 关联/搜索结果上下文；未来重做计算应按当前产品关联 BOM 集合核验，不能全库求和。

包装工钱的人工上游输入为以下 5 项，均为產品表普通数字；它们不是本页外围独立输入框，若网页需要录入工时，应另设“计时/产能”表单：

| 字段 | 输入含义 |
|---|---|
| `準備工時分` | 准备耗时：分 |
| `準備工時秒` | 准备耗时：秒 |
| `包裝工時分` | 包装耗时：分 |
| `包裝工時秒` | 包装耗时：秒 |
| `準備工時數量` | 本次计时的产品/包装数量；两套单包公式共用 |

换汇的汇率为 0、计时数量为 0、报价积数为 100 时存在除零问题。未来网页需明确空值与非法分母的校验，并保留 FileMaker 的计算异常状态；不能把 `?` 或失败一律转换为 0。当前页面货币符号/小数位属于显示格式，不代表原公式已经 Round。

## 3. 產品售價：完整 10 字段

这是 EX-Price、台币出厂、RMB 出厂和补充说明的实际来源。**本表没有 calculation 或 summary 字段。** 三种售价没有字段级自动换汇公式；四项业务字段的自动输入均为 `TextFormatRemove ( Self )`，替换现有值、允许人工修改。

| 字段 | 类型 | 自动输入/逻辑 | 编辑建议 |
|---|---|---|---|
| `產品編號` | 普通文本 | 无自动输入 | 系统绑定产品，不作为自由输入 |
| `Price` | 普通数字 | 去格式 | 人工维护 EX-Price |
| `台灣售價` | 普通数字 | 去格式 | 人工维护台币出厂价 |
| `RMB售價` | 普通数字 | 去格式 | 人工维护 RMB 出厂价 |
| `售價備註` | 普通文本 | 去格式 | 人工录入补充说明 |
| `零售價` | 普通数字 | 无自动输入 | 另一个零售价；当前外围 Retail Price 未绑定它，不自动合并 |
| `created_at` | 普通时间戳 | 创建时间戳 | 系统维护 |
| `created_by` | 普通文本 | 创建账户名 | 系统维护 |
| `updated_at` | 普通时间戳 | 修改时间戳 | 系统维护 |
| `updated_by` | 普通文本 | 修改账户名 | 系统维护 |

现有 Web `finance.py` 通过产品 `product_sku / 系統產品編號` 与售价 `產品編號` 精确匹配，并拒绝重复/歧义。这里描述的是现有 Web 绑定策略，不将它冒充为已经逐条核对的 FileMaker 关系图条件。2026-09-23 导入报告已有 289 个异常产品，不能假定原数据全局一对一；本次没有重扫全库业务记录。

## 4. 客户群报价：ProductPrice / ProductPriceCustomer

## 7. 网页表单落地建议

1. **人工产品输入**：SKU、中英文名称、MOQ、审核（按权限）、Retail Price、报价积数、成本加成、汇率、A/B 积分、组装成本、其他成本、时薪、最低库存量。若要维护计时或尺寸，另加相应原始输入项。
2. **关联售价输入**：EX-Price、台币出厂、RMB 出厂、补充说明，保存到独立售价记录；不能混入产品主表 PATCH。
3. **编辑页隐藏**：主清单 13 个计算字段；补充项中的 CBM、库存汇总、客户列表计算同样隐藏，不随表单提交。在详情页按需要只读展示。
4. **系统/独立流程维护**：系统产品编号从 SKU 派生；建档人与创建日期只读；PrePaid 通过独立业务操作；报价客户群通过选择客户维护关联。
5. **保持两套售价独立**：產品售價、ProductPrice 客户群报价、產品::Retail_Price_USD、產品售價::零售價不可仅凭名字相似合并。
